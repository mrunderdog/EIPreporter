# EIPreporter

## Goal
Build an internal EIP/ERC intelligence service.

## Product Scope

### Ethereum Tech Radar
- Track new EIPs/ERCs
- Track status changes
- Track Final and Withdrawn proposals
- Summarize Ethereum technical trends

### KGLD Opportunity Radar
- Identify proposals relevant to KGLD
- Analyze DeFi, Wallet UX, RWA opportunities
- Recommend actions

## Reporting Policy
- Collect daily
- Report weekly
- High priority alerts only

## Output Language
Korean-first
